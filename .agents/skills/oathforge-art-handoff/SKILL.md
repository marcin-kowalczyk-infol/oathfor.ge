# oathforge-art-handoff

Read repository-root docs/art/art-bible.md and docs/art/pipeline.md. Inspect the supplied images using available image tools; if you cannot view them, state that limitation.

Compare identity, silhouette, materials, camera/light, transparency and small-screen legibility against selected canonical references. Distinguish intentional progression from visual drift. Identify cleanup, layers or rig work still needed.

Keep source artwork in ignored graphics. For approved exports, record stable ID/version, dimensions, transparency, target use and provenance. Do not export or overwrite unrelated files. If generation is requested, use the available generation tool/skill; this skill does not assume a vendor or subscription.

Sources: local owner direction in docs/decisions/0001-project-foundation.md and art pipeline; ignore semantics in [Git](https://git-scm.com/docs/gitignore).
